# Glossário

| Termo | Definição |
|-------|-----------|
| **Admin** | Usuário responsável por uma família; único admin por família |
| **Assistido** | Pai, mãe ou parente sendo cuidado — entidade `Parent` no código |
| **Cuidador** | Irmão ou familiar membro da família que registra ações de cuidado |
| **Família** | Grupo de irmãos/cuidadores coordenando o cuidado dos mesmos assistidos |
| **Família ativa** | Família selecionada no client; enviada via `X-Family-Id` |
| **Feed** | Lista cronológica de atividades da família ativa |
| **Goal / Meta** | Objetivo financeiro coletivo da família (ex.: "Comprar óculos simples") |
| **Member** | Participante da família (não admin) |
| **Parent** | Entidade de domínio para assistido (Pai, Mãe, etc.) |
| **Hub de cuidado** | Visão do produto — central colaborativa de ações de cuidado parental |
| **Streak** | Dias consecutivos com pelo menos uma ligação |
| **FamilyMembership** | Vínculo N:N entre User e Family com role |
