# Glossário

| Termo | Definição |
|-------|-----------|
| **Admin** | Usuário responsável por uma família; único admin por família |
| **Família** | Grupo de irmãos cuidando dos mesmos pais |
| **Família ativa** | Família selecionada no client; enviada via `X-Family-Id` |
| **Feed** | Lista cronológica de atividades da família ativa |
| **Goal / Meta** | Objetivo financeiro coletivo da família |
| **Member** | Participante da família (não admin) |
| **Parent** | Pai ou mãe sendo cuidado |
| **Streak** | Dias consecutivos com pelo menos uma ligação |
| **FamilyMembership** | Vínculo N:N entre User e Family com role |

Fonte original: PRD §12 (arquivado em `.specs/archive/prd-v1.1.md`).
